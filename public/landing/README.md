# Landing-page product captures

All eight product screenshots currently used on the homepage were captured on 2026-11-08. Five desktop captures use the current Accessible Smart Map web application; three native captures use the iOS app in the iPhone 18 Pro simulator running iOS 27.0. The local frontend at `http://127.0.0.1:3102/map/` used the existing development proxy to the real backend on port 8000. No mock responses, generated imagery, substituted interface content, or fabricated routes were used. Desktop captures used an isolated anonymous browser session with light theme and public destinations. The native app used the existing installed development build with current project JavaScript served by local Metro and a temporary `EXPO_PUBLIC_END_POINT=http://127.0.0.1:8000` override. Native capture used public endpoints; no account identity, saved places or search-history lists appear in the published image, and no device location was used as a route endpoint.

Desktop screenshots are 1440 × 1000. The native simulator capture is 1206 × 2622, captured at the original device resolution. Raw PNG evidence is in `output/homepage-redesign/recapture/`. The Next.js developer overlay was hidden during capture; product UI and data were left intact. `walking-draft.png`, `wheelchair-settings.png` and `wheelchair-settings-ready.png` are unpublished drafts. `navigation-mobile.png` is the superseded responsive-web capture; `navigation-native.png` is also superseded preview-mode evidence. Current native sources are `navigation-live-native.png`, `bus-arrivals-native.png` and `bus-route-native.png`.

Published images are converted using Sharp at WebP quality 88 (desktop) / 90 (mobile), with no cropping or compositing. Desktop responsive variants are 480, 768 and 1024 px wide; mobile variants are 360 and 720 px wide. Desktop map attribution remains inside the screenshots. Native navigation overlays cover the map's attribution in the actual app, so the homepage includes linked map credits beside that image. The small `brand-mark.webp` derives from the existing app icon.

Legacy `route-native.webp` and superseded `navigation-mobile.webp` / `navigation-native.webp` files and their variants remain in the working tree but are not referenced by the current homepage. The new native screenshot is displayed at its original aspect ratio, preserving the status bar and complete app interface.

Screenshots are historical UI demonstrations. Times, service conditions, elevations and route results are not current service guarantees. Green segments represent matched sidewalk data, not verified passability or accessibility certification. Elevation is modeled, not a field survey.

The homepage uses the map's theme variables in `src/app/theme.css`, Geist / Noto Sans TC fonts and theme provider. GSAP handles reveals, scroll emphasis, route-line motion, reading progress and desktop card stacking; Motion handles mode and feature transitions and the mobile menu. Per the requested homepage behavior, animations remain enabled independently of the system reduced-motion setting; the map application's behavior is unchanged.

The feature overview now explicitly covers voice turn-by-turn guidance, live bus arrivals/filtering/reminders, text/voice AI assistance, nearby accessibility facilities, parking, weather/air quality, mapped indoor venues, hazard reports and SOS. Simulator location was cleared after capture. Native application code was not changed for capture.
